# proposal：第12月 W2 专题化变更——光谱指数专题框架 + 郑州高新区建筑用地变化报告

> 状态：**applied（2026-09-11，selftest 5 套全绿 21+17+14+8+10 / e2e 郑州 10/10 + 深圳湾回归 7/7 / 郑州双景入库 49SGU / 真实报告落盘，证据见 tasks.md）**

## 背景

用户真实需求：出一份「郑州市高新区建筑用地变化报告」。现状核实（2026-09-10 explore）：

- 链路能跑通约 80%：report_engine 全链路、变化检测双方法、`satellite_download.py --real`（earth-search STAC + 远程 COG 裁剪）数据源是全网的
- 缺口①：`BBOX`/日期/输出名硬编码深圳湾（`satellite_download.py:48`），`REAL_BANDS` 只有 B2/B3/B4/B8 四个 10m 波段——**NDBI 建筑用地指数需要 SWIR（B11），做不了**
- 缺口②：`report_engine.collect()` 里 `region="深圳湾"` 与标题硬编码（模板本身已泛化，零"水域"字样）
- 缺口③：无专题判定——spectral_diff 是全谱变化，郑州高新区周边农田/裸地噪声会全部混入；U-Net"城市"类跨域（深圳湾合成训练→郑州真实）不可信
- 缺口④：PostGIS 只有深圳区界，无法按"郑州高新区"行政边界精确裁剪

用户追问"绿化用地等其他专题怎么办"后，设计从 builtup 专用方法升级为**光谱指数专题框架（方案 B+，用户确认）**：各专题在数学结构上同构（指数 + 阈值判定 + 两期差分），只差指数公式/波段/阈值。

**项目定位**：学习计划第12月 W2（文档+开源准备）之前的跨域泛化实战检验——用真实需求验证系统"换个区域换个专题还能不能跑"，是开源前最有说服力的测试用例。

## 目标（验收标准）

1. **专题框架**：`THEMES` 注册表（纯数据）+ `index_change` 泛化引擎（唯一实现）；新增"绿化用地"专题 = 加一个 dict 条目零新代码
2. **数据获取泛化**：`satellite_download.py` 支持 `--region`/`--start`/`--end` 参数化；`REAL_BANDS` 扩展 SWIR（B11/B12）；郑州高新区两期同月影像成功入库（覆盖度 ≥50%）
3. **阈值不拍脑袋**：NDBI/NDVI 阈值经真实影像直方图探查标定后回填，标定过程与数字留档
4. **专题报告**：`collect()` 参数化 region/theme，产出《郑州高新区建筑用地变化分析报告》（md + html），含两期专题面积、新增/消失净变化（km²），数字全部来自 state（数字闸门不破防）
5. **multi_agent 集成**：一句自然语言「对比郑州高新区 2023 和 2025 的建筑用地变化并出报告」→ planner 路由 index_change → 端到端出报告（e2e 断言）
6. **回归不破坏**：既有 4 波段旧 COG 全链路不变（e2e 7/7 + 全部 selftest）

## 非目标（范围克制）

- 行政边界精确裁剪（方案 C 内容拆出：需外部矢量 + rasterize mask，等 OSM relation 验证后另立变更；本次 bbox 近似 + 报告声明）
- 绿化/水域专题只**注册**（证明框架可扩展），不做端到端实测与报告——避免范围膨胀
- 插件系统 / 动态加载 / 抽象基类——"注册表 dict + 单引擎函数"足够，第三次重复出现时再升级
- LLM 参与专题判定（专题判定是确定性光谱计算，与 W4"意图-渲染分层"同理：LLM 只选 theme 枚举，不碰计算）

## 红旗预登记

① **NDBI 阈值风险**：农田/裸土 NDBI 同样偏高，单指数必误判——NDVI 联合判定缓解但不根除，阈值必须真实影像标定（design D4）；② **郑州数据不确定性**：同 MGRS tile 双时相配对 + 同月季相 + 云量 <10% 可能凑不齐——覆盖度评分兜底，实在配不齐报告如实标注数据限制；③ **SWIR 是 20m 波段**重采样到 10m 网格，报告分辨率声明要诚实；④ **6 波段格式变更**影响面：真彩色预览 bands=(3,2,1) 索引不变、旧 4 波段 COG 不动，但 cog_reader/manifest 需按波段数自适应（design D3）；⑤ bbox 近似 ≠ 行政区边界（面积误差估 10-20%），报告头部声明；⑥ e2e 依赖网络 + DeepSeek token（同 W4 先例，selftest 全部零网络）。
