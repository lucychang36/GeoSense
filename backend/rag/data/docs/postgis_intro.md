# PostGIS 空间数据库入门

## 什么是 PostGIS

PostGIS 是 PostgreSQL 的空间扩展，为关系型数据库增加了存储和查询地理对象的能力。
它遵循 OGC 简单要素规范，是开源 GIS 栈的基石。

## 空间数据类型

PostGIS 核心是 geometry 类型，支持点、线、面等几何对象。
geometry 在平面坐标系下计算；geography 类型则在椭球面上用测地线计算，适合大范围距离。

## 空间索引

空间查询的性能关键在于 GiST 索引。通过 R-Tree 结构，ST_Intersects、ST_DWithin 等
谓词可以从全表扫描降为索引范围扫描，千万级数据也能亚秒返回。

## 常用空间函数

ST_DWithin 判断两个几何是否在指定距离内，返回布尔值，能利用索引加速。
ST_Intersects 判断是否相交，是最常用的空间过滤谓词。
ST_Transform 用于坐标系转换，投影坐标系以米为单位，适合面积和距离计算。

## 坐标系与单位

WGS84（EPSG:4326）用经纬度，单位是度。Web 墨卡托（EPSG:3857）和 CGCS2000 分带投影
用平面米制坐标。做面积、距离计算前，务必先投影到米制坐标系，否则结果单位错误。
