OGC WMS 服务简介

WMS（Web Map Service）是 OGC 定义的地图服务标准，服务端按请求动态渲染并返回指定范围的地图图片。

核心请求参数

  • REQUEST：操作类型，如 GetMap、GetCapabilities
  • LAYERS：要渲染的图层
  • BBOX：请求范围（最小经度、最小纬度、最大经度、最大纬度）
  • WIDTH / HEIGHT：输出图片尺寸

与 WFS 的区别

WMS 返回渲染好的图片，适合展示；WFS 返回矢量数据本身，支持空间过滤查询，适合分析与编辑。

典型应用

WMS 广泛用于 WebGIS 底图与专题图发布，可与 WMTS 瓦片服务配合提升大规模访问性能。
